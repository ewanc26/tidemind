# Asset provenance

All island, building, tree, water, and interface geometry is original C++ drawing
code in `src/ui.cpp`. There are no downloaded sprites or proprietary game assets.

`fonts/NotoSans.ttf` is Noto Sans, downloaded from the Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/notosans

It is distributed under the SIL Open Font License 1.1, included in
`fonts/OFL.txt`. The font is bundled so the game does not depend on a system font
or download anything at runtime. The binary is tracked directly in Git.
